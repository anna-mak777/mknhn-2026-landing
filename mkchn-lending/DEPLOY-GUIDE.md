# 🌐 ЧАСТЬ 1 · ДЕПЛОЙ

## Вариант A · Netlify Drop (рекомендуется, самый быстрый)

**Время:** 2 минуты до публичного URL.

1. Откройте https://app.netlify.com/drop
2. Перетащите папку `public/` в окно браузера
3. Через 10 секунд получите URL вида `https://amazing-tesla-abc123.netlify.app`
4. **Проверьте** открывается ли сайт, листается ли, работает ли меню
5. Для подключения своего домена:
   - В Netlify: Site settings → Domain management → Add custom domain
   - В регистраторе домена (RU-CENTER / REG.RU / Timeweb) добавить A-запись или CNAME на Netlify
   - SSL-сертификат Netlify оформит автоматически через Let's Encrypt
6. При обновлениях — просто перетащите папку `public/` заново (замена через drag-and-drop)

**Плюсы:** бесплатно, автоматический HTTPS, CDN по всему миру, быстрый откат к предыдущей версии.
**Минусы:** нет FTP для прямого доступа к файлам.

## Вариант B · Vercel

```bash
npm i -g vercel
cd public
vercel
```
Отвечаете на вопросы в CLI → получаете URL. Деплой через `vercel --prod`.

## Вариант C · GitHub Pages

1. Создать репозиторий (public или private)
2. Положить содержимое `public/` в корень репо (не саму папку `public/`, а её содержимое)
3. Settings → Pages → Source: `main` branch, folder `/ (root)` → Save
4. Через 2-3 минуты сайт по адресу `https://<ваш-github>.github.io/<repo-name>/`
5. Для своего домена: в репо создать файл `CNAME` с одной строкой — вашим доменом

## Вариант D · Обычный хостинг (Timeweb / Beget / RU-CENTER)

Для хостинга с SSH/FTP:
1. Загрузить всё содержимое `public/` в корень домена (обычно `public_html/` или `www/`)
2. Проверить что `index.html` открывается по корневому URL
3. **Важно:** убедитесь что .htaccess или настройки сервера НЕ переписывают URL (лендинг одностраничный, якорные ссылки должны работать)

- [ ] Проверить все якорные ссылки меню (прокрутка к секциям)

# 🔌 ЧАСТЬ 3 · ИНТЕГРАЦИЯ С CRM

Это ваша зона ответственности, Андрей. Формa уже заготовлена под параллельную отправку.

## Как это работает

При отправке формы `script.js` делает два параллельных POST-запроса:
1. **Formspree** → письмо на `info@proftreker.ru` (всегда работает)
2. **CRM webhook** → создание лида в CRM (включается опционально)

Если CRM недоступна — email всё равно уходит. Если наоборот — лид попадёт в CRM и Анна увидит его там. **Fallback-защита в обе стороны.**

## Что сделать

### Шаг 1 — подготовить endpoint в CRM

Нужен POST endpoint, который принимает JSON такого вида:

```json
{
  "project":     "МКЧН-2027",
  "source":      "landing-mkchn-2026",
  "submittedAt": "2026-10-03T18:30:00.000Z",
  "pageUrl":     "https://mkchn-2026.ru/#kp-request",
  "company":     "ЕВРАЗ",
  "name":        "Иванов Иван Иванович",
  "position":    "HR-директор",
  "email":       "ivanov@evraz.ru",
  "phone":       "+7 (912) 345-67-89",
  "comment":     "Планируем команду на 2027. Прошу подробную программу."
}
```

Endpoint должен:
- Принимать POST с `Content-Type: application/json`
- Возвращать 200/201 на успех (тело ответа не важно)
- Иметь **CORS-заголовок**: `Access-Control-Allow-Origin: https://<ваш-домен>` (или `*` если домен ещё не финализирован)

Пример минимального Node.js обработчика (если CRM на Express):
```js
app.post('/api/leads', express.json(), (req, res) => {
  const lead = req.body;
  // Создать карточку в проекте МКЧН-2027
  crm.createLead({
    pipeline: 'МКЧН-2027',
    title: `${lead.company} — ${lead.name}`,
    contactEmail: lead.email,
    contactPhone: lead.phone,
    customFields: {
      position: lead.position,
      source: lead.source,
      comment: lead.comment
    }
  });
  res.sendStatus(201);
});
```

### Шаг 2 — настроить CORS

Если CRM на другом домене (а она скорее всего там), браузер потребует CORS-заголовки:

```
Access-Control-Allow-Origin:  https://mkchn-2026.ru
Access-Control-Allow-Methods: POST, OPTIONS
Access-Control-Allow-Headers: Content-Type
```

Обработчик OPTIONS (preflight) тоже нужен — возвращает 200 с теми же заголовками.

### Шаг 3 — вписать URL в script.js

Найдите в файле `public/script.js` строку:
```js
var CRM_WEBHOOK_URL = null;
```

Замените на реальный URL:
```js
var CRM_WEBHOOK_URL = 'https://crm.proftreker.ru/api/leads';
```

Передеплойте сайт (перетащите папку `public/` в Netlify Drop заново).

### Шаг 4 — тестирование

1. Отправить тестовую заявку с лендинга
2. Проверить что:
   - Пришло письмо на `info@proftreker.ru` (Formspree)
   - Создалась карточка в CRM в проекте «МКЧН-2027»
3. В браузере DevTools → Network → увидеть **два** POST-запроса: один в formspree.io (200), второй в ваш CRM endpoint (201)

### Если CRM недоступна или вернула ошибку

Код написан так, что CRM-ошибка **не блокирует** отправку в Formspree:
```js
fetch(CRM_WEBHOOK_URL, {...}).catch(function(err){
  console.warn('CRM webhook failed:', err);
});
```

То есть пользователь всё равно увидит «Заявка принята», письмо уйдёт, но лида в CRM не будет. Это логируется в консоль браузера.

### Авторизация (если нужна)

Если CRM требует API-ключ, добавьте header в `script.js`:
```js
headers: {
  'Content-Type': 'application/json',
  'X-API-Key': 'ваш-ключ'
}
```

⚠️ **НЕ кладите в клиентский JS никакие секретные токены** — они будут видны любому в DevTools. Для публичного endpoint CRM должна либо:
- Использовать публичный write-only API-ключ
- Проверять `Origin` header и доверять только вашему домену
- Иметь rate limiting (защита от спама)

# 🖼 ЧАСТЬ 4 · ЛОГОТИПЫ УЧАСТНИКОВ И ПАРТНЁРОВ

## Требования к размерам

### 👥 Логотипы участников (блок «Участники 2026»)
Сетка 3×3, 9 ячеек, пропорция каждой **3:2**.

| Параметр | Значение |
|---|---|
| **Canvas (единая рамка)** | **600 × 400 px** |
| **Лого внутри** | занимает **70–80%** от ширины или высоты canvas (что меньше), центровано |
| **Отступ от края canvas** | ≥ **15%** со всех сторон |
| **Формат** | **SVG** (идеал) или **PNG-24** с прозрачностью |
| **Фон** | **прозрачный**, НЕ белый |
| **Цвет лого** | полноцветный оригинальный логотип компании |

### 🏛 Логотипы партнёров (блок «Институциональные партнёры»)
Сетка 4×2, 8 ячеек, пропорция каждой **~2:1** (вытянутая под длинные названия).

| Параметр | Значение |
|---|---|
| **Canvas** | **500 × 240 px** |
| **Лого внутри** | **75–85% canvas** |
| **Отступ от края** | ≥ **15%** |
| **Формат** | **SVG** или **PNG-24** с прозрачностью |
| **Фон** | **прозрачный** |

## 📐 Workflow подготовки лого (универсальный)

### В Figma / Illustrator / Inkscape (векторные редакторы)
1. Создать новый artboard **600×400** для участников / **500×240** для партнёров
2. Вставить оригинальный логотип (SVG или высокого качества PNG)
3. Отмасштабировать: лого должен занимать 70-80% canvas
4. Центровать по вертикали и горизонтали
5. Экспортировать:
   - **SVG** — Export → SVG (predпочтительно, векторный, не теряет качества)
   - **PNG** — Export → PNG, прозрачный фон, 2x (1200×800 для участников, 1000×480 для партнёров) → браузер сам даст retina

### В GIMP / Photoshop (растровые редакторы)
1. New document 600×400 (или 500×240), **transparent background**
2. Drag-and-drop лого
3. Отмасштабировать + центровать
4. File → Export As → PNG → убедиться что `Save transparency` включен

## 🧩 Как заменить плейсхолдеры в HTML

### Участники (найти в `index.html` блок `<div class="participants-grid">`)

**Сейчас:**
```html
<div class="participant-slot">
  <svg width="28" height="28" ...>...</svg>
</div>
```

**Заменить на:**
```html
<div class="participant-slot filled" title="Т Плюс">
  <img src="assets/img/logos/participants/tplus.svg" alt="Т Плюс">
</div>
```

**Добавить в `styles.css`** (если ещё нет этих правил):
```css
.participant-slot.filled{
  background:var(--c-bg);
  border:1px solid var(--c-paper-2);
  border-style:solid;
}
.participant-slot.filled:hover{
  background:var(--c-bg);
  border-color:var(--c-dark);
  transform:translateY(-2px);
  box-shadow:0 8px 20px rgba(49,38,59,.08);
}
.participant-slot img{
  max-width:100%;
  max-height:100%;
  width:auto;
  height:auto;
  object-fit:contain;
}
```

### Партнёры (найти блок `<div class="partners-grid">`)

**Сейчас:**
```html
<div class="partner-card empty">
  <svg width="28" height="28" ...>...</svg>
</div>
```

**Заменить на:**
```html
<div class="partner-card" title="НАРК">
  <img src="assets/img/logos/partners/nark.svg" alt="НАРК">
</div>
```

Класс `empty` **убрать** — он для плейсхолдеров с пунктирной рамкой.

Стили для `.partner-card img` уже в CSS, менять ничего не нужно.

### Если лого не влезло / выглядит мелким
Проверьте что canvas соответствует требованиям (600×400 или 500×240) и лого занимает 70-85% его площади. Если лого «тонет» в большом canvas — пересохраните с меньшим внешним отступом.
